# COMP9312

Coursework for **COMP9312 — Data Analytics for Graphs** (UNSW).
This repository is used as a personal cross-platform workspace for all
assignments and projects in the course.

## Structure

| Folder | Contents |
| ------ | -------- |
| [`assignment1/`](assignment1/) | Assignment 1 — disjoint sets, BFS, graph representations, DFS order, DAG longest path. Question sheet (`ass1.md`) and worked solutions (`ass1_solution.md`). |

Further assignments and projects will be added as additional top-level folders
(e.g. `assignment2/`, `project/`).

## File naming convention

For every assignment, each solution comes in two forms:

- `*_solution.md` — readable Markdown solution.
- `*_solution_pdf.md` — the same content as **LaTeX source**; copy the whole file
  into Overleaf and compile to get the PDF for submission.
